# blog

The UQ MARS blog, a home for documenting and summarising the many activities of the UQ MARS community.

## Contributing

To contribute an article to the blog, begin by forking this repository.
All contributions will need to be submitted by Pull Request to ensure review from the Executive Team.

Once you have a fork set up, add a new markdown (.md) file to the `_posts` directory.
Ensure that you provide accurate frontmatter following either existing articles, or
[this GitHub guide](https://docs.github.com/en/pages/setting-up-a-github-pages-site-with-jekyll/adding-content-to-your-github-pages-site-using-jekyll).

Before creating a PR, ensure that you have [tested locally](https://docs.github.com/en/pages/setting-up-a-github-pages-site-with-jekyll/testing-your-github-pages-site-locally-with-jekyll)
and are happy with the formatting.
